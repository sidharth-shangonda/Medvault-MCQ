## Run The MERN App Locally

```bash
npm install
cp .env.example .env
```

Put your MongoDB Atlas connection string into `.env` as `MONGODB_URI`, then import the extracted PYQs:

```bash
npm run import:questions
npm run server:start
```

In another terminal:

```bash
npm run client:dev
```

Open `http://localhost:5173`.

Without `MONGODB_URI`, the API runs in file mode from `data/questions.json`. That is useful only for quick development because user accounts and progress are in memory and reset when the server restarts. For your 50 users, use MongoDB Atlas.

To check the production build locally:

```bash
npm run build
npm start
```

Open `http://localhost:5050`.

## Legacy Offline Page

`index.html` still works as a standalone offline page using `assets/question-bank.js`. The MERN app lives in `client/` and `server/`.

## Image Review

Use the React app's `Image Audit` tab. It shows image-linked questions with extracted media so the image-to-question mapping can be verified in batches.

## User Accounts

The app has email/password registration and login. Passwords are hashed with bcrypt. Progress APIs require a JWT token, so each user has separate:

- attempts
- sessions
- bookmarks
- mistakes
- spaced-revision due dates
- subject/chapter completion
- subject/chapter accuracy

## GitHub And Render Deployment

Do not commit `.env` or `Pyqs_ed8.pdf`. The extracted question JSON and media assets are the app data needed at runtime.

1. Create a GitHub repo from this folder.
2. Push the code to GitHub.
3. In Render, create a Blueprint from the repo. The included `render.yaml` creates one Node web service.
4. Add `MONGODB_URI` when Render asks for the synced secret value.
5. Render will run `npm ci && npm run build`, then `npm run import:questions`, then `npm start`.

Render environment variables:

```bash
MONGODB_URI=your-atlas-connection-string
JWT_EXPIRES_IN=7d
QUESTION_JSON_PATH=data/questions.json
```

`JWT_SECRET` is generated by the Render Blueprint. If you create the service manually instead of using the Blueprint, set `JWT_SECRET` yourself.

Important: the extracted media folder is about 397 MB. GitHub and Render can handle this as normal files, but it makes deploys heavier. For a larger production version, move `assets/media` to object storage/CDN and store only image URLs in MongoDB.
